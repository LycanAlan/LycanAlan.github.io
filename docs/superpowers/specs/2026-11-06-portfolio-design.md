# Portfolio design (approved 2026-11-06)

## Goal
A one-page portfolio for Ali Ansari that a recruiter or engineering manager can skim in under a
minute and come away with: ranked 1st of 142 for six semesters, builds systems and measures them,
learns new fields fast, available for Jan to Jun 2027 internships and 2027 SDE roles.

## Direction: flood fill
- Light, cool white page. Near-black ink. One accent: Micromouse wall-post red.
- Hero signature: a live Micromouse maze (dark floor, white walls, red posts). Flood fill spreads
  from the goal, then the mouse runs the shortest path. Clicking a cell moves the goal; a button
  makes a new maze. Respects prefers-reduced-motion.
- Type: Archivo Variable (width axis; expanded for display), Martian Mono Variable for numbers.
- Every project is led by its measured result, shown as a before/after comparison where one exists.
- Banned (impeccable): eyebrow labels, 01/02 section numbers, gradient text, glass, identical card
  grids, side-stripe borders, emoji icons.

## Sections
1. Header: name, nav (Work, Record, Profiles, Contact), Resume button.
2. Hero: name, thesis line, rank and availability, Resume / Email / GitHub / LinkedIn; maze.
3. Work: Distributed Rate Limiter, PitchLens (flagships, large rows), Micromouse, Panchayat,
   Dispute Autopilot, VoidCart (compact rows), plus a line pointing to the rest of GitHub.
4. Record: six-semester rank strip, CGPA 8.70, three national Micromouse wins, 1,072 problems.
5. Competitive programming: Codeforces rating history chart (76 contests, snapshot) and profile
   rows for Codeforces, LeetCode, CodeChef, GitHub.
6. How I work: principles with evidence, learning timeline, what I'm looking for, toolbox.
7. Experience and leadership: TA, Phoenix Robotics Club.
8. Contact: email with copy button, links. No form.

## Constraints
- Copy follows human-writing: no em dashes, no hollow intensifiers.
- Phone number appears only inside the resume PDF.
- Hosted on GitHub Pages at https://lycanalan.github.io (user site repo LycanAlan.github.io).
- Out of scope: dark mode, blog, contact form backend, live API fetching.
